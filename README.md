# 🍕 Pizza Sales Analysis (Python)

This project uncovers insights through cleaning, merging, and visualizing pizza restaurant sales data using Python and pandas.

**Dataset source:** * Kaggle*

## 🎯 Project Objectives
- Calculate total revenue, total quantity sold, and total orders
- Identify top and bottom performing pizza types
- Analyze average price and average pizzas per order
- Discover sales trends by day, month, hour, and pizza size
- Generate clear visualizations to support findings

## 🛠 Tech Stack
- **Python 3**
- **pandas** — data cleaning and analysis
- **matplotlib** — charts and visualization
- **Jupyter Notebook** — interactive analysis

## 💡 Key Insights
- Large pizzas generate the most revenue, contributing 45% of total sales.
- The busiest sales period is Friday between 12 PM and 1 PM.
- Only 16 out of 32 pizza types perform above the median sales quantity.
